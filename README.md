# Golden Years Haven

MASTER PROMPT — PROFESSIONAL OLD AGE HOME WEBSITE



Create a complete, highly professional, modern, emotionally warm and visually impressive website for an Old Age Home / Senior Care Organization.



The website is being created as a serious academic/project website, but it must look and feel like a professionally designed real-world NGO or senior-care organization website.



1. CORE OBJECTIVE



Build a polished, responsive and accessible website that communicates:



- Care

- Dignity

- Safety

- Compassion

- Respect for senior citizens

- Community

- Trust

- Hope

- Human connection



The website should NOT look childish, overly colorful, generic, or like a basic college project.



The visual quality should be comparable to a premium NGO, healthcare, senior-living or social-impact organization website.



---



2. TECHNOLOGY



Build the website using:



- HTML5

- CSS3

- Vanilla JavaScript



Do NOT require a paid framework, premium library, paid API, or paid service.



The website must work as a static website and be deployable on Cloudflare Pages.



Keep the code clean, organized and production-ready.



Use separate files:



- index.html

- style.css

- script.js



Create an assets/images folder structure where appropriate.



Do not put important content directly into JavaScript if it can reasonably be kept in HTML.



---



3. DESIGN DIRECTION



Create a sophisticated visual identity based around:



Primary palette



Use a warm, trustworthy and elegant palette:



- Deep Forest Green — #23483A

- Sage Green — #6F8F7A

- Warm Cream — #F7F1E5

- Soft Beige — #E8DDCC

- Muted Terracotta — #B96F52

- Charcoal — #29332F

- White — #FFFFFF



Use the colors carefully.



The overall appearance should feel:



warm + premium + peaceful + trustworthy + human



Avoid excessive gradients, neon colors, extremely bright colors, excessive shadows and clutter.



Use subtle gradients only where they improve the design.



---



4. TYPOGRAPHY



Use elegant typography.



Suggested combination:



- Headings: Playfair Display or another sophisticated serif

- Body: Inter / Poppins / similar clean sans-serif



Typography must have:



- Excellent hierarchy

- Comfortable line spacing

- Good readability

- Responsive sizing

- Proper contrast



Use large editorial-style headings for major sections.



---



5. GLOBAL DESIGN SYSTEM



Create a consistent design system for:



- Buttons

- Cards

- Section headings

- Icons

- Forms

- Navigation

- Testimonials

- Statistics

- Image galleries

- Content blocks



Use:



- Rounded corners, but not excessively rounded

- Soft shadows

- Subtle borders

- Generous whitespace

- Elegant spacing

- Consistent container widths



The website should feel premium and spacious.



---

The hero must immediately communicate warmth, dignity and trust.



Use a cinematic but tasteful image treatment.

20. ANIMATIONS



Animations are extremely important, but they must remain elegant.



Use:



- Fade-in

- Fade-up

- Slide-in

- Scale-in

- Image reveal

- Button hover

- Card hover

- Navigation transition

- Counter animation

- Parallax-style effects where appropriate



Use IntersectionObserver for scroll-triggered animations.



Do NOT make every element move.



Animations should communicate quality, not distraction.



Respect:



prefers-reduced-motion



and reduce/disable non-essential animations for users who request reduced motion.



---



21. MICRO-INTERACTIONS



Add refined interactions:



- Buttons slightly lift on hover

- Cards subtly rise

- Images gently zoom

- Navigation links have animated indicators

- Form fields have elegant focus states

- Gallery images have polished hover effects

- Back-to-top button appears after scrolling

- Mobile menu opens smoothly



Keep everything subtle and premium.

- Accessible buttons

- Heavy unnecessary libraries

- Autoplay videos

- Huge unoptimized images

- Unnecessary JavaScript

- Excessive animation



Use lazy loading for images where appropriate.



Keep the site lightweight and Cloudflare Pages friendly.
